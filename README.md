# Servlet Simple Calculator

A small web calculator made with Java Servlet and run on Apache Tomcat using IntelliJ IDEA.
The user enters two numbers, selects an operator and the result is shown on the same page.

## 1. About the Project

This project is a simple calculator that works in the browser. The page is generated by a Java servlet
(`CalculatorServlet`). When the user presses the **Calculate** button, the form is sent to the servlet with
the POST method, the servlet calculates the answer and sends the page back with the result.

I made this project to learn how a servlet receives data from an HTML form, processes it and sends
a response back to the browser.

## 2. Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Modulus (%)
- Shows an error message if the user enters something that is not a number
- Shows an error message for division by zero and modulus by zero
- The numbers and the operator stay in the form after pressing Calculate
- Whole-number answers are shown without `.0` (for example `5` instead of `5.0`)

## 5. How to Run

1. Open IntelliJ IDEA Ultimate and open the project `servlet-SimpleCalculator`.
2. Open `pom.xml`. Make sure `maven.compiler.source` and `maven.compiler.target` are `17` (not `8`), then click the Maven reload button.
3. Check that `CalculatorServlet.java` is inside `src/main/java/com/example/calculator`.
4. At the top right, select **Tomcat 10.1.61** from the run configuration list.
5. Go to **Edit Configurations → Deployment** and check that the `servlet-SimpleCalculator:war exploded` artifact is added.
6. In the **Server** tab, set the URL to:
   `http://localhost:8080/servlet_SimpleCalculator_war_exploded/calculator`
7. Click the green **Run** button.
8. The browser opens the calculator page. Enter two numbers, choose an operator and press **Calculate**.

If the page is not found (404), check the *Application context* in the Deployment tab and use the same name in the URL.

## 6. How It Works

- `doGet()` runs when the page is opened. It shows an empty calculator form.
- `doPost()` runs when the form is submitted. It reads `num1`, `num2` and `op` using `request.getParameter()`.
- The servlet converts the numbers with `Double.parseDouble()` and uses a `switch` statement to do the calculation.
- If something is wrong (invalid number, divide by zero) an `error` message is shown instead of the result.
- `render()` writes the HTML page using `PrintWriter`.
- A small `esc()` method is used so that special characters typed by the user do not break the page.

## 9. Problems I Faced

- The browser kept showing the old *Hello World* page after running. This happened because IntelliJ opened the old URL.
  I fixed it by changing the URL in the Tomcat run configuration and deleting `HelloServlet.java` and `index.jsp`.
- Java version in `pom.xml` was 8, but Tomcat 10.1 and Servlet API 6.0 need a newer version. I changed it to 17.
